Explain 教学回放

两个单元都由同一个声明式 schema 编译：可步进、可重置；请求失败时保留下方静态结果，不执行任意 JavaScript 或在线模型调用。

已预渲染 2 个解释单元；等待版本化 JSON 校验。

Agent 工具调用：声明到结果

用同一 explain schema 展示一次受约束的 Agent 工具调用回放，不执行任意代码。

explain.agent-tool-call · 模型：agent-tool

  1. 声明工具
    调用者选择已登记的工具 ID 与操作名。 说明：工具能力来自静态 manifest。
  2. 校验参数
    运行时检查输入类型与大小，再决定是否允许执行。 说明：无效参数在本地停止。
  3. 回放结果
    展示预先编译的结果说明，失败时仍可阅读静态回退。 说明：本原型不发起在线调用。

使用 Tab 聚焦控件，按 Enter 或空格回放下一步；结果会在状态区播报。

第 1/3 步：声明工具

静态回退说明

工具调用由声明、参数校验和静态结果回放组成，不执行任意代码。

  1. 选择已登记工具
  2. 校验输入契约
  3. 显示可审计的结果说明

队列入队：从点击到本地状态

演示一个状态单元如何把动作变成可回放、可清除的本地队列状态。

explain.queue-enqueue · 模型：queue

  1. 捕获动作
    用户点击入队，任务壳记录 enqueue 动作。 说明：不会上传输入或状态。
  2. 计算转移
    纯状态转移把一个项目追加到队列末尾。 说明：同一状态可被重放。
  3. 保存并反馈
    结果保存到本站 IndexedDB，并通过状态区播报。 说明：清除本站数据不会影响文章。

使用 Tab 聚焦按钮，按 Enter 或空格逐步播放；当前步骤会在状态区播报。

第 1/3 步：捕获动作

静态回退说明

队列动作依次经过捕获、状态转移和本地持久化三个阶段。

  1. 捕获 enqueue 动作
  2. 追加队列项目
  3. 保存到本站本地存储
